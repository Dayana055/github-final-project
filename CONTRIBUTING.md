# Pautas de Contribución

¡Gracias por tu interés en contribuir a este proyecto!

Todas las contribuciones, informes de errores, correcciones de errores, mejoras en la documentación, mejoras e ideas son bienvenidas.

## Cómo contribuir
1. Haz un fork de este repositorio.
2. Crea una nueva rama para tu cambio (`git checkout -b mejora-nueva`).
3. Realiza tus modificaciones y haz commit (`git commit -m "Agrega mejora"`).
4. Sube los cambios a tu fork (`git push origin mejora-nueva`).
5. Abre una Solicitud de Extracción (Pull Request).
