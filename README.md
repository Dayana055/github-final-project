# Calculadora de Interés Simple

Este proyecto contiene un script en Bash para calcular el interés simple a partir del capital inicial, la tasa de interés anual y el período de tiempo en años.

## Fórmula utilizada
Interés Simple = (Capital * Tasa de Interés * Tiempo) / 100

## Uso
Ejecuta el script desde la terminal:
```bash
bash simple-interest.sh
