# Simple Interest Calculator

A simple calculator application and open-source project for calculating simple interest based on principal, annual interest rate, and time period.

## Formula
Simple Interest ($s$) is calculated with the formula:
$$s = \frac{p \times t \times r}{100}$$

Where:
* **p** = Principal amount (initial capital)
* **t** = Time period (in years)
* **r** = Annual interest rate (percentage)

## Usage
Run the Bash script `simple-interest.sh` in your terminal and enter the requested values when prompted.
